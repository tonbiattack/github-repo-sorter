GitHub Repo Sorter

GitHub のリポジトリ一覧を、作成・Fork・Push を統合した最近の活動順に並べ替える Chrome 拡張です。

アクセストークン（任意）

非公開リポジトリも一覧に含める場合に登録します。未登録の場合は公開リポジトリのみを取得します。

確認中…

  • 必要な権限: クラシックトークンは repo スコープ、fine-grained トークンは対象リポジトリの Metadata: Read です。
  • トークンはブラウザのセッション領域（chrome.storage.session）にのみ保存し、ページには渡しません。ブラウザを終了すると消えます。
  • 外部サーバーへの送信は行いません。通信先は api.github.com のみです。

使い方

  1. GitHub のプロフィールで「Repositories」タブを開きます（https://github.com/<owner>?tab=repositories）。
  2. GitHub 標準の「Sort」から「作成・Fork・Push順」などを選びます。標準項目を選ぶと GitHub の一覧に戻ります。
  3. 並び替え・絞り込みは owner ごとに保存され、次回訪問時に復元されます。
