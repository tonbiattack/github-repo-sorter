GitHub Repo Sorter

GitHub のリポジトリ一覧を、作成・Fork・Push を統合した最近の活動順に並べ替える Chrome 拡張です。

アクセストークン（任意）

非公開リポジトリも一覧に含める場合に登録します。未登録の場合は公開リポジトリのみを取得します。

確認中…

この端末のディスク上にトークンが平文で残ります。共用 PC や、端末の盗難・マルウェアが心配な場合は オフのままにしてください。オフの場合、ブラウザを終了するとトークンは消えます。

  • 推奨は fine-grained トークンで、対象リポジトリの Metadata: Read のみを付与します。 クラシックトークンの repo スコープは読み取り専用ではありません （書き込み権限を含むため、より強い権限になります）。
  • トークンは content script には渡しません。保存先は既定で chrome.storage.session （ブラウザ終了で消去）です。
  • 外部サーバーへの送信は行いません。通信先は api.github.com のみです。
  • 認証に失敗した場合や、別アカウントでログインしている場合は、公開一覧への切り替えを 自動では行いません。エラーとして表示します。

使い方

  1. GitHub のプロフィールで「Repositories」タブを開きます（https://github.com/<owner>?tab=repositories）。
  2. GitHub 標準の「Sort」から「作成・Fork・Push順」などを選びます。標準項目を選ぶと GitHub の一覧に戻ります。
  3. 検索欄・Type・Language・Visibility は GitHub 標準の操作をそのまま使えます。
  4. 並び順・絞り込みは owner ごとに保存され、次回訪問時に復元されます。
